# Choose a workflow

Read the selected skill's full instructions before executing. These are installed workflow names, not additional MCP tools. Source data comes from CF where supported, user-supplied evidence or the user's separately connected tools. Every conclusion must follow the selected skill's evidence rules.

| Outcome | Installed skill |
| --- | --- |
| Find creator candidates | find-creators |
| Quick evidence-backed overview | light-research |
| Comprehensive creator analysis | deep-research |
| Analyze content evidence | content-research |
| Understand the transformation offered | find-the-big-promise |
| Capture audience struggles in their words | hear-the-real-struggle |
| Identify the creator's method | decode-the-secret-sauce |
| Understand differentiation | find-the-standout-factor |
| Map emotional themes | map-the-emotional-pull |
| Select strongest evidence and content | find-the-gold |
| Analyze offers | offer-cd3-analysis |
| Map funnels and monetization | funnel-monetization-map |
| Assess partnership fit | partnership-fit-readiness |
| Prepare evidence for personal outreach | personalization-brief |
| Find and verify contact email | find-verify-email |
| Research public Meta ads | meta-ads-research |

Web browsing or retrieval may be needed for linked websites, offers and funnels that CF tools do not retrieve. Email verification requires a separately connected verifier such as MillionVerifier; finding an address does not verify deliverability. Never invent access to these tools or assume a CF subscription pays for them. User-supplied evidence can support analysis when fresh acquisition is unnecessary or unavailable.

Personalization Brief produces evidence and outreach angles. The user's agent may draft a message when asked; sending requires a separately connected outreach tool and explicit user authorization. No CF skill or connector automatically sends messages. External-tool requirements are decided per workflow; do not make every optional integration an onboarding prerequisite.
