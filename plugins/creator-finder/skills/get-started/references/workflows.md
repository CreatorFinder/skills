## Compose only what the task needs

Use connected CF data where supported, user-supplied evidence, available browsing and separately authorized tools. Inspect actual tool schemas before promising a source. CF supports Instagram, YouTube and TikTok operations and public Meta Ad Library data; individual fields, transcripts and comment pages depend on the operation/provider. Websites, offer pages and funnel steps may require browsing or user-supplied files. None of these sources guarantees complete coverage.

For example, a creator link can lead to a light snapshot and then an offer analysis if that helps the user's decision. A supplied list can be assessed without repeating discovery. A personal outreach draft can use supplied research after template retrieval. Missing optional tools can justify a narrower result, but unavailable private CF retrieval stops the CF workflow and never permits recreating its method.

Email verification requires a separately connected verifier such as MillionVerifier and its actual response; a found address stays unverified until then. Drafting uses authenticated outreach templates and actual sender context. Sending requires a separate connected tool and explicit authorization. Do not make verification or sending integrations a condition for ordinary creator research.

Explain criteria before acquisition, preserve the finite request ceiling and receipt/retry rules in [data mechanics](data-contract.md), and report uncertainty. Recommend the next action that follows from the evidence, rather than automatically chaining paid workflows.
